# SFU Student

Помощник студента СФУ: Telegram-бот + Mini App. Расписание, преподаватели,
сервисы ЭИОС и напоминания. Бот и приложение работают с одним профилем:
группа, выбранная в боте, сразу видна в приложении, и наоборот.

## Что умеет

- Расписание на сегодня, завтра и неделю (чётность недели определяется автоматически).
- «Сейчас идёт» — текущая пара и сколько до конца.
- Поиск преподавателя по фамилии: предметы, группы, занятия.
- Мини-приложение с онбордингом: институт → группа → подгруппа.
- Ежедневная рассылка расписания в удобное время.
- Ссылки на Личный кабинет, eCourses, библиотеку и портал СФУ.
- Светлая и тёмная тема.

## Локальный запуск в Windows

1. Скопируй `.env.example` в `.env` и укажи `BOT_TOKEN` от BotFather.
2. Установи зависимости: `py -m pip install -r requirements.txt`.
3. Запусти: `py run.py`.
4. API: `http://127.0.0.1:8080`, Mini App: `http://127.0.0.1:8080/miniapp`.

Не отправляй `.env` в GitHub и не пересылай токен.

## Как связаны бот и приложение

Один источник правды — SQLite в `data/`. Оба интерфейса пишут и читают через API.

Авторизация в Mini App двумя способами:

1. **Внутри Telegram** — браузер присылает `initData`, сервер проверяет подпись по `BOT_TOKEN`.
2. **В любом браузере** (GitHub Pages, локально, Telegram Desktop) — бот кладёт в ссылку
   подписанный токен `?t=...&api=...`; сервер проверяет его тем же `BOT_TOKEN`.
   Токен живёт 30 дней, хранится в `localStorage` браузера.

Поэтому мини-апп можно держать где угодно: главное, чтобы в ссылке был `api=`
с адресом сервера. Бот подставляет его сам.

## Переменные окружения

| Переменная | Зачем |
|---|---|
| `BOT_TOKEN` | токен бота; им же подписываются сессии Mini App |
| `MINIAPP_URL` | адрес страницы Mini App; на Render не нужен |
| `PUBLIC_API_URL` | адрес API, если страница живёт на другом домене |
| `DATA_DIR` | папка базы и кэша; на Render — `/var/data` |
| `SFU_TZ` | часовой пояс, по умолчанию `Asia/Krasnoyarsk` |
| `SSL_VERIFY` | проверка сертификатов при запросах к СФУ |
| `TEACHER_CACHE_TTL` | сколько минут кэшировать индекс преподавателей |

## Основные маршруты API

| Маршрут | Назначение |
|---|---|
| `GET /api/health` | проверка сервиса |
| `GET /api/catalog` | институты, группы, подгруппы |
| `GET /api/me` | профиль и избранное |
| `POST /api/profile` | группа, подгруппа, тема, уведомления |
| `GET /api/schedule?day_offset=&week=` | расписание |
| `GET /api/teachers?q=` | поиск преподавателей |
| `GET /api/teachers/{ФИО}` | карточка преподавателя |
| `GET /api/hub` | ЭИОС и новости |

Старые маршруты (`/api/user/{id}`, `/api/schedule/{id}`, `/api/teacher/{id}`)
сохранены для уже опубликованной версии Mini App на GitHub Pages.

## Деплой на Render

В корне есть `render.yaml`: один Web Service запускает бота и API, SQLite и кэш
пишутся на диск `/var/data`. В переменных окружения достаточно указать `BOT_TOKEN`.

1. Залей проект в GitHub (приватный репозиторий, без `.env` и `data/`).
2. В Render создай Blueprint из репозитория.
3. Проверь `https://ИМЯ-СЕРВИСА.onrender.com/api/health`.
4. Открой бота в Telegram: кнопка «Открыть приложение» поведёт на Render,
   где всё уже работает.

## Опубликованные адреса

| Что | Адрес |
|---|---|
| Репозиторий | https://github.com/zxclown88391/sfu-student |
| Mini App на GitHub Pages | https://zxclown88391.github.io/sfu-student/miniapp/ |

GitHub Pages отдаёт только статику, поэтому странице нужен адрес API. Он передаётся
параметром `?api=https://…` в ссылке (бот подставляет его сам) либо
переменной `PUBLIC_API_URL`.

Важно: страница на Pages открывается по HTTPS, а браузер блокирует запросы к
`http://`. Поэтому API для неё должен быть по HTTPS — то есть Render.
Внутри Telegram это неважно: там мини-апп обычно открывается прямо с сервера API.

Если Mini App остаётся на GitHub Pages — обнови там `miniapp/index.html` из этого
проекта и задай `PUBLIC_API_URL` с адресом Render. Бот подставит нужные параметры сам.

## Структура

```
api/            FastAPI: авторизация, профиль, расписание, преподаватели
auth/           подписанные сессионные токены
bot/            aiogram: меню, выбор группы, поиск, уведомления
database/       SQLite: пользователи, избранное, миграции
schedule/       клиент API СФУ, форматирование, индекс преподавателей
integrations/   ссылки ЭИОС и новости
notifications/  ежедневная рассылка
miniapp/        Mini App одним файлом
```
